## 怎么用

- **找内容**：左侧目录按大师分组，进入任意分区后按序号阅读
- **搜全文**：侧边栏搜索框，输入关键词直接搜 995 篇正文
- **顺读**：每页底部有「上一篇 / 下一篇」，可跨章节连续阅读
- **护眼**：右下角 ◐ 按钮切换深色模式，默认跟随系统
